Marimay toolchain (Stage 0 private preview)

Current claim: local checker-backed slice; not a public alpha.
Usage: mmay <command> [options]

Available workflow:
  fmt       Canonically format source and manifests
  check     Check the implemented source and typed MIR slice
  test      Run built-in tests (VM by default)
  run       Run a program (VM only in this preview)
  build     Build a host-native executable

Available inspection:
  version   Show release contract and build identity
  help      Show help for a recognized command

Staged (recognized but not executable):
  add audit bench doc exec explain fix fuzz generate init list
  outdated remove update vendor vet why

Global options:
  --help
  --version
  --color auto|always|never
  --diagnostic human|short|json
  --quiet
  --verbose

Run 'mmay help <command>' for availability, owner, and examples.
