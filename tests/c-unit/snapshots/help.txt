Marimay toolchain (Stage 0 bootstrap)

Usage: mmay <command> [options]

Everyday workflow:
  fmt       Canonically format source and manifests
  check     Check source and verified typed MIR
  test      Run built-in tests (VM by default)
  run       Run a program (VM by default)
  build     Build an executable (native by default)

Packages and maintenance:
  init add remove update list why outdated vendor audit
  doc vet fix fuzz bench generate

Inspection:
  version   Show compiler and runtime build identity
  explain   Explain diagnostics and inferred behavior
  help      Show help for a command

Global options:
  --help
  --version
  --color auto|always|never
  --diagnostic human|short|json
  --quiet
  --verbose

Run 'mmay help <command>' for task-oriented examples.
