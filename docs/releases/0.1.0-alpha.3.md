## Changes since 0.1.0-alpha.2

- Experimental basic language server `mmay lsp` (decisions D113, D119, D120;
  PR #7). Diagnostics, navigation for top-level symbols/locals/record fields,
  standard-library source/API views, completion, validated rename and
  formatting over bounded cached analyses. Unit, integration, differential
  and editor-feature tests included. See [editor support](../editor-support.md).
  Available commands now include `lsp`.
- Record construction uses coalesced storage (decision D118, PR #6): the
  per-record header/fields allocation pair and stack root-buffer copies are
  removed. Local A/B screening on the unchanged corpus (Apple M2, six
  interleaved rounds, 11 samples after 3 warmups, medians of per-round
  ratios): record-create −24.4% (22.69 → 17.08 ms, per-round ratios
  0.745–0.769), catalog-pipeline −1.9%; controls flat within the session
  noise floor. Evidence:
  `docs/implementation/evidence/d118-coalesced-record-ab-2026-11-09.md`.
- The split/graphemes intrinsics stop allocating temporary root scaffolding
  per call (decision D117, PR #5). The measured target rows (word-frequency,
  normalize-title) stay inside the session noise floor on the loaded
  screening machine, so no percentage is claimed; the per-piece managed
  publication cost remains and GitHub issue #3 stays open. Evidence:
  `docs/implementation/evidence/d117-strided-root-split-ab-2026-11-09.md`.

## Downloads and installation

Same distribution shape as
[`0.1.0-alpha.2`](0.1.0-alpha.2.md#downloads-and-installation): macOS 15+ on
Apple Silicon (`arm64`) and Intel (`x86_64`), `marimay-0.1.0-alpha.3-darwin-ARCH`
`.pkg` and `.tar.gz` with SHA-256 siblings, plus a portable source archive.
Packages are unsigned and unnotarized. Follow
[macOS installation](../install-macos.md); each version installs to its own
prefix and an upgrade keeps the previous version's receipt.

## Scope and compatibility

Source language, VM-native semantics, bounded standard library and all wire
contracts are unchanged from
[`0.1.0-alpha.2`](0.1.0-alpha.2.md#scope-and-compatibility). The only
inventory change is the addition of the experimental `lsp` command; staged
commands and all compatibility statements are unchanged.
