## Changes since 0.1.0-alpha.1

- Managed Map/Set key hashing moves from SipHash-2-4 to the seeded
  `mmay_hash_seeded` owner (XXH64 structure, both injected collection seeds;
  decision D115, PR #4). Unobservable per the ordered-collection decision;
  insertion order, equality, probing and D055 accounting are unchanged.
  Local A/B screening on the unchanged corpus (Apple M2, medians of two
  alternating passes, every run checksum-clean): unique-set −21.9%,
  frequency-map −13.4%, map-string −11.7%, map-int −8.8%, rune-frequency
  −6.3%; all other rows within the local noise floor. Evidence:
  `docs/implementation/evidence/d115-seeded-hash-ab-2026-11-09.md`.
- Known remaining performance obligations are unchanged by this alpha:
  `word-frequency` and `normalize-title` remain allocation-bound in the
  `text.split`/`graphemes` intrinsics (tracked in GitHub issue #3).

## Downloads and installation

Same distribution shape as
[`0.1.0-alpha.1`](0.1.0-alpha.1.md#downloads-and-installation): macOS 15+ on
Apple Silicon (`arm64`) and Intel (`x86_64`), `marimay-0.1.0-alpha.2-darwin-ARCH`
`.pkg` and `.tar.gz` with SHA-256 siblings, plus a portable source archive.
Packages are unsigned and unnotarized. Follow
[macOS installation](../install-macos.md); each version installs to its own
prefix and an upgrade keeps the previous version's receipt.

## Scope and compatibility

Command inventory, VM-native semantics, bounded standard library and all
compatibility statements are as documented for
[`0.1.0-alpha.1`](0.1.0-alpha.1.md#scope-and-compatibility); nothing in this
alpha changes the source language, wire formats or runtime contracts.
