## Downloads and installation

The binary scope is macOS 15+ on Apple Silicon (`arm64`) and Intel (`x86_64`).
Each host has `marimay-0.1.0-alpha.1-darwin-ARCH.pkg` and `.tar.gz`, each with a
SHA-256 sibling. A portable source archive is also included. Packages are
unsigned and unnotarized; checksums and provenance are not Developer ID
signatures or Apple notarization.

Follow [macOS installation](../install-macos.md) for checksum verification,
standard Installer use, global command layout, and explicit recovery steps.
Native compilation requires local Apple Command Line Tools with AppleClang 16+
under the fixed installed policy. The package contains the compiler/VM, both
native runtime profiles, headers, bounded standard library, offline docs,
source kit, provenance and SBOM; it does not download a compiler or edit PATH.

## Scope and compatibility

Available commands are `build`, `check`, `doctor`, `fmt`, `help`, `init`, `run`,
`test`, and `version`. VM execution is the default for `run` and `test`; native
builds use the installed Apple toolchain. `mmay doctor --json` describes the
actual selected compiler and both version-matched runtime profiles.

The source surface and bounded standard library are experimental and may
change in a later alpha with an explicit migration note. Public `.myb`
compatibility, networking/tasks, registries/dependencies, production LSP,
FFI, cross compilation, desktop support, self-hosting and performance parity
are not promised. The first prerelease adds distribution and toolchain policy,
not new source-language syntax or semantics.
