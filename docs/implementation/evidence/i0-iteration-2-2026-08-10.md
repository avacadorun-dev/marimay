## Test surfaces

- vector growth, element retention, zeroed extension, shrinking, bounds, allocation failure, and cleanup;
- owned binary bytes including embedded zero and sentinel ownership;
- arena multi-block allocation, maximum alignment, reset, first-allocation failure, and cleanup;

## Known risks and next slice

I0 remains incomplete and has only run on macOS arm64/AppleClang. The source manager currently uses linear file lookup and monotonic in-memory snapshot IDs; cryptographic snapshot identities arrive with the hashing slice. It intentionally retains all overlays until session disposal, with editor eviction policy deferred behind the same ownership interface.

The next slice is portable hashing, open-addressed maps, path normalization, and process/file adapters, followed by Tier 1 CI. It must add SHA-256 snapshot identities, collision/adversarial map cases, Windows/POSIX path fixtures, atomic file operations with injected failure, and offline child-process tests without weakening the source ownership API.
