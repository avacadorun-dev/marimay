Gate: I3 typed-bytecode VM and I4 portable-C backend vertical slice.

Environment: macOS arm64, AppleClang 17.0.0, CMake 4.4.2.

## Delivered slice

- Accepted D044 fixes `f64` to raw IEEE 754 binary64 semantics. Decimal source
  conversion is locale-independent, exact, bounded, and rounds nearest-even.
  Arithmetic temporarily establishes nearest-even, forces a binary64 result,
  canonicalizes arithmetic NaNs, and restores the complete caller environment.
  Unary negation toggles the sign bit; comparisons implement IEEE zero and NaN
  rules directly over raw bits.
- The host gate checks binary64 layout, rounding control, subnormal production
  and subnormal consumption (FTZ and DAZ). MIR, VM, and native emission reject
  only programs that use `f64`; feature-zero programs remain available. Native
  generated C repeats the gate on its target before executing `main`.
- Source checking supports decimal literals, inferred and declared top-level
  constants, unary negation, `+`, `-`, `*`, `/`, equality/ordering, exact f64
  calls, and `+=`, `-=`, `*=`, `/=` for locals and mutable record fields.
- MIR, bytecode, verifier, disassembler, codec, VM, direct calls, and generated
  C preserve raw f64 bits. Opcode wire IDs 31 through 39 and bytecode feature
  bit two are append-only; feature-zero bytes remain unchanged.
- Decimal parsing and runtime arithmetic are separate C17 translation units,
  so native output links only the allocation-free runtime helper.
- The normative tour now includes a compact `f64` interpolation example.

This does not define `f32`, textual floating-point formatting, managed arrays,
indexing, or the final matrix-multiplication example.

## Verification coverage

- Decimal vectors pin ties-to-even, the minimum subnormal and its exact half,
  the minimum normal, maximum finite, overflow to infinity, underscores, and
  the `2^53 + 1` rounding boundary. Every internal big-integer allocation is
  failed in order until success with zero live allocations after each attempt.
- Hostile rounding-mode tests run the same tie case under nearest, downward,
  upward, and toward-zero and require identical result bits plus restoration of
  the original mode. Finite values, signed zero, infinities, NaNs, divide by
  signed zero, comparisons, copies, calls, and return boundaries are pinned.
- Codec tests cover exact metadata/IDs, raw-bit encoding, disassembly, every
  prefix truncation, missing and spurious f64 feature bits, malformed types and
  registers, deterministic re-encoding, and legacy feature-zero bytes.
- Native tests compile and execute generated C under C17 warnings-as-errors at
  O0 and O2 with strict FP flags. A source-level fixture traverses lexer,
  parser, checker, MIR, bytecode program encode/decode, VM, and generated C and
  observes the same raw binary64 result.
- The frontend fuzz corpus now includes a valid top-level f64 constant and
  compound arithmetic seed. The local AppleClang distribution still lacks the
  libFuzzer runtime, so no successful fuzz campaign is claimed.
