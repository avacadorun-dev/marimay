# Private experiment artifact records

Experimental implementation archives and candidate patches are retained in
the owner's private recovery collection. They are not distributed in this
repository or its published Git history. This index records identities and
historical filenames; it does not provide downloads. Public measurements and
decisions remain historical evidence, without a claim that these private
experiments can be reconstructed from the public checkout.

The machine-readable index is [private-artifacts.json](private-artifacts.json).
Dates, source revisions and protocol digests in older reports refer to the
preserved original experiment, whose full history remains private.
