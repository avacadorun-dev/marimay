# Historical implementation evidence

Evidence reports dated before the 2026-08-23 Marimay rebrand record commands,
paths, targets, schemas, and artifacts exactly as they existed when those
checks ran under the historical Ruda identity. Their prose, filenames, and
external URLs are intentionally not rewritten as if the old runs used the new
identity.

Relative repository links may be updated when a tracked target is renamed, so
that the reports remain navigable. New implementation and roadmap text uses
Marimay, `mmay`, `.my`, and the other current identities defined by D001.
