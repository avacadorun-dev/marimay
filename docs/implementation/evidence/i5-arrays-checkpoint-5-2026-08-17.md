# Preview `Array<T>` — checkpoint 5 — 2026-08-17

Gate: I5 managed data and standard core. Checkpoint status: locally complete;
I2, I3, I4, and I5 remain `in-progress`. This evidence records the fifth
preview checkpoint and does not claim a Tier 1 release gate.

Authority: accepted D045, D033, the language Array/indexing rules, the
standard-library collections contract, the execution managed-memory/rooting
contract, and the checkpoint-5 requirements in `checkpoints.md`.

## Delivered slice

- Generic arrays now use a canonical bytecode array-type table containing the
  bytecode element tag and exact managed-layout index. New generic bundles do
  not serialize source `RudaTypeId` values or host pointers; the old f64 tags
  remain only for decoding legacy f64-only preview bundles.
- `Array<T>` flows through checker lowering, MIR, bytecode encode/decode and
  verification, VM descriptors and operations, and generated portable C17.
  Descriptor lookup is keyed by exact element type/layout provenance, including
  nested managed arrays; scalar cells are not conservatively traced.
- The checker accepts inferred and explicit `arrayOf` forms, free and dot-call
  `push`, `length`, checked indexing, indexed compound assignment, nested
  arrays, and `Array<int>` sorting/searching code. `push` has the D045
  `Result<void, ArrayGrowthError>` surface.
- The normative iteration spelling is frozen as D033's
  `for const item of array`, with one iterator, immutable exact-`T` binding,
  cleanup on every control-flow exit, and generation-based mutation rejection.
  The full iterator lowering remains part of the broader I5 iterator gate.
- Existing `Array<f64>` and `Array<Array<f64>>` matrix coverage remains green.
  VM/native tests include collect-before-allocation, exact G4002 extrema and
  spans, descriptor/provenance rejection, malformed generic bytecode, and
  generated-C compilation/execution without raw runtime pointers.

## Verification coverage

- `tests/c-unit/test_checker_arrays.c` covers source construction, explicit
  type arguments, free/dot `push`, nested generic arrays, indexed mutation,
  sorting/searching, MIR verification, generic table round trips, malformed
  table/construction/push metadata, VM execution, G4002, and generic checker
  fail-every-allocation cleanup with zero live allocations and bytes.
- `tests/c-unit/test_native_c_emitter_arrays.c` covers a generic `Array<int>`
  through MIR, VM, and generated C17/native execution, including descriptor and
  push emission. Existing differential tests cover f64 matrices, nested roots,
  resource ceilings, collect-before-allocation, and native G4002 identity.
- `tests/c-unit/test_bytecode_vm_arrays.c` continues to cover encoded array
  allocation failure sweeps, runtime allocation failure, malformed metadata,
  bounds extrema, root cleanup, resource limits, and descriptor provenance.
- Formatter fixtures cover `arrayOf`, dot `push`, indexing, and indexed `+=`;
  existing grammar/generics fixtures cover nested `Array<T>` syntax and
  explicit generic call syntax.
