This workspace has no `.git` metadata or configured remote, so the workflow could not be dispatched and a literal clean-checkout build could not be demonstrated. YAML parsing is not CI execution. GCC, MSVC, the Windows file/process adapters, Linux, and macOS x86_64 therefore remain unverified.

POSIX replacement syncs file contents before `rename`, but does not yet promise directory-entry durability across a power loss; the public contract is atomic visibility, not crash-durable commit. Apple LeakSanitizer is unavailable in this toolchain, as recorded in iteration 1. No Ruda source reaches MIR, VM, or native execution, so differential, formatter, parser, and Ruda-program performance evidence remains inapplicable.
